# 4-接口列表

本文基于 `dolphinscheduler-api` 模块中的后端 Controller 源码整理 REST API 清单，并按功能维度归类。

说明：

- API Server 配置了 `server.servlet.context-path: /dolphinscheduler/`。
- 下表中的 API URL 是去掉 context path 后的相对路径；实际访问时需要加 `/dolphinscheduler` 前缀。
- 例如表中的 `GET /projects`，实际访问路径是 `GET /dolphinscheduler/projects`。
- 本文主要列业务 REST API；Master、Worker、Alert 之间的 Netty RPC 属于内部进程间接口，没有 HTTP API URL，因此不放入主表。

## 1. 认证、会话与 OAuth/OIDC

来源 Controller：`LoginController`

| 方法 | API URL | 功能描述 |
| --- | --- | --- |
| POST | `/login` | 用户名密码登录，返回会话信息、用户信息和安全配置 |
| GET | `/login/sso` | SSO 单点登录入口 |
| POST | `/signOut` | 当前用户退出登录 |
| DELETE | `/cookies` | 清除浏览器中的 session cookie |
| GET | `/oauth2-provider` | 查询当前启用的 OAuth2 登录提供方 |
| GET | `/oidc-providers` | 查询当前启用的 OIDC 登录提供方列表 |
| GET | `/redirect/login/oauth2` | 重定向到 OAuth2 登录授权页 |
| GET | `/login/oauth2/code/{providerId}` | 处理 OIDC/OAuth2 登录回调 |
| GET | `/oauth2/authorization/{providerId}` | 按 providerId 重定向到 OIDC 授权入口 |

## 13. 功能维度总览

| 功能维度 | 主要接口前缀 | 主要用途 |
| --- | --- | --- |
| 认证与会话 | `/login`、`/signOut`、`/oauth2-*` | 登录、退出、SSO、OAuth2、OIDC |
| 用户与权限 | `/users`、`/access-tokens` | 用户管理、资源授权、访问令牌 |
| 项目管理 | `/projects`、`/projects/{projectCode}/project-*` | 项目、项目参数、项目偏好、项目 Worker Group |
| 工作流定义 | `/projects/{projectCode}/workflow-definition` | DAG 定义、版本、发布、任务节点、变量 |
| 任务定义 | `/projects/{projectCode}/task-definition` | 任务定义版本、发布、详情、上游关系 |
| 执行控制 | `/projects/{projectCode}/executors` | 运行工作流、批量运行、暂停、停止、重跑、任务控制 |
| 实例查询 | `/projects/{projectCode}/workflow-instances`、`/projects/{projectCode}/task-instances` | 工作流实例、任务实例、甘特图、变量、子工作流 |
| 定时调度 | `/projects/{projectCode}/schedules` | 调度创建、更新、上线、下线、预览 |
| 资源文件 | `/resources` | 文件上传、在线创建、查看、下载、删除 |
| 数据源与云服务 | `/datasources`、`/cloud` | 数据源管理、连接测试、库表字段查询、Azure Data Factory |
| 运行资源 | `/tenants`、`/queues`、`/environment`、`/cluster`、`/worker-groups`、`/k8s-namespace`、`/task-group` | 租户、队列、环境、集群、Worker Group、K8s 命名空间、任务组 |
| 告警与插件 | `/alert-groups`、`/alert-plugin-instances`、`/ui-plugins`、`/dynamic`、`/favourite` | 告警组、告警实例、UI 插件、动态任务类型、收藏任务类型 |
| 监控统计审计 | `/monitor`、`/projects/analysis`、`/projects/audit` | 服务节点、数据库、运行执行器、统计图表、审计日志 |
| 运维与文档 | `/swagger-ui.html`、`/v3/api-docs`、`/actuator/*` | API 文档、健康检查、指标导出 |
