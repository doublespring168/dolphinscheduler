# 1、AMD64打包
## 1.1、加载基础镜像

```

# 运行 -p321 
git ls-files -z | rsync -avz --from0 --files-from=- -e "ssh -p 321" ./ darcy@100.127.219.48:/home/darcy/Downloads/ala-ds


```

## 1.2、打包

```

# 运行

cd /home/darcy/Downloads/ala-ds
./mvnw clean package -Pstaging -DskipUT=true

cd gyyun-dist
docker rm -f gyyun-api gyyun-master gyyun-worker gyyun-alert

sh src/main/docker-amd64/docker-push.sh r.gyykj.com/gyy-base 3.4.3-SNAPSHOT ala-ds

# 查看部署包
ll docker-images

cp -r target/gyyun-3.4.3-SNAPSHOT-bin/plugins docker-images

```
